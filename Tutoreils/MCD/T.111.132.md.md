# Formaliser les fonctionnalités de l'Administrateur

## 1. Gestion des Articles

* Lister les articles.
* Ajouter un article.
* Modifier un article.
* Supprimer un article.

## 2. Gestion des Catégories

* Lister les catégories.
* Ajouter une catégorie.
* Modifier une catégorie.
* Supprimer une catégorie.

## 3. Parcours fonctionnel : Ajouter une catégorie

* **Acteur :** L'administrateur.
* **Écran de départ :** Page de gestion des catégories.
* **Action :** L'administrateur clique sur le bouton « Ajouter une catégorie ».
* **Résultat :** Le formulaire de création d'une catégorie s'affiche.

## 4. Synthèse fonctionnelle

L'administrateur peut gérer les articles et les catégories. Pour chaque entité, il peut lister, ajouter, modifier et supprimer les éléments.
